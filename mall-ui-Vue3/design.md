# 设计规范（Design System）

> 风格定位：**淡紫马卡龙 · 浅色 · 悬浮圆角容器**，参考电商后台参考图设计语言。
> 所有新页面必须严格遵循本规范，保证全站风格统一。
> 技术栈：Vue3 + Element Plus + SCSS。设计 token 定义于 `src/assets/styles/variables.module.scss`。

---

## 2. 字体

### 2.1 字体栈

```
-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC",
"Hiragino Sans GB", "Microsoft YaHei", sans-serif
```

### 2.2 字号 / 字重 / 行高层级

| 层级 | 字号 | 字重 | 行高 | 用途 |
|---|---|---|---|---|
| 页面大标题 | 22~26px | 700 | 1.3 | 登录标题、欢迎语（可用玫红或渐变） |
| 卡片/模块标题 | 16~18px | 600 | 1.4 | "Today's data" 式区块标题 |
| 数据大数字 | 24~28px | 700 | 1.2 | 统计卡核心数值 |
| 正文 | 14px | 400 | 1.6 | 表单、表格、段落 |
| 辅助说明 | 12~13px | 400 | 1.5 | 注解（Yesterday xxx）、副标题 |
| 按钮文字 | 14~15px | 600 | 1 | 主操作按钮 |

**对比原则**：数值与注解至少差 2 个字级且字重差 ≥ 200；标题用字重不用大字号。

|---|---|

| 内容区 padding（.app-container） | 20px |

## 4. 组件样式

### 4.1 圆角

| Token | 值 | 用途 |
|---|---|---|
| `--radius-xs` | 6px | 小标签 |
| `--radius-sm` | 8px | 按钮、输入框 |
| `--radius-md` | 12px | 数据卡、表格、图标方块 |
| `--radius-lg` | 16px | 标准卡片、弹窗内元素 |
| `--radius-xl` | 20px | 应用容器、大弹窗 |
| `--radius-full` | 999px | 菜单激活胶囊、药丸标签、圆形图标 |

### 4.2 阴影（紫调柔和，禁止硬阴影）

| Token | 值 | 用途 |
|---|---|---|
| `--shadow-sm` | `0 1px 2px + 0 2px 8px rgba(124,116,160,0.06)` | 输入框、小元素 |
| `--shadow-md` | `0 4px 16px rgba(124,116,160,0.10)` | 常规卡片 |
| `--shadow-lg` | `0 12px 32px rgba(124,116,160,0.14)` | 悬浮卡片、下拉 |
| `--shadow-xl` | `0 24px 56px rgba(124,116,160,0.18)` | 弹窗、应用容器 |
| 主色阴影 | `0 8px 24px rgba(240,67,110,0.28)` | 主按钮 hover |

### 4.3 按钮

| 属性 | 规则 |
|---|---|
| 高度 | 主操作 40~44px / 常规 32~36px |
| 圆角 | 8px（胶囊 CTA 可用 999px） |
| 主按钮 | 背景 `#f0436e`，白字 600，阴影 `0 2px 8px rgba(240,67,110,0.22)` |
| Hover | 背景 `#d9305c` + `translateY(-1px~-2px)` + 主色阴影 |
| 次按钮 | 白底 + `#eceaf4` 边框，hover 边框加深 |
| 过渡 | `transition: all 0.25~0.3s ease` |

### 4.4 卡片

| 属性 | 规则 |
|---|---|
| 背景 | `#ffffff`；数据卡可用马卡龙浅底或 `#f4f3f8` |
| 边框 | `1px solid #eceaf4`（或无边框纯阴影） |
| 圆角 | 16px（数据卡 12px） |
| 阴影 | `--shadow-sm`，hover 升级 `--shadow-md` + `translateY(-2px)` |
| 内边距 | 20~24px |

### 4.5 导航栏 / 侧边栏

| 元素 | 规则 |
|---|---|
| 顶部白色横带 | logo 区 + 导航栏 + 标签条 + 侧边栏**共用 `--navbar-bg`（纯白 #ffffff）**，组成整宽横带 + 左列的 L 形白框；横带底部 1px 极淡分界 `rgba(38,35,54,0.05)`；侧边栏默认 `sideTheme: 'theme-light'` |
| 导航栏 | 高 64px，左右 padding 20px，无独立阴影 |
| 右侧图标 | 36px 圆形按钮，hover 玫红轻染 `rgba(240,67,110,0.08)` + 文字变玫红 |
| 头像区 | 32px 头像 + 白边圆环（`0 0 0 2px #fff, 0 0 0 3px rgba(240,67,110,0.25)`）+ 昵称 600，hover 胶囊轻染 |
| 标签条 TagsView | 高 40px，与导航栏同色，底部 1px 分界线；标签项**药丸圆角**，激活态玫红底白字 + 玫红浅影（禁用 Vue 绿 #42b983） |
| 侧边栏 | 透明背景融入容器；logo 区 64px 与导航栏同色；菜单项高 44px、圆角胶囊 |
| 菜单激活 | 玫红文字 600 + `rgba(240,67,110,0.10)` 胶囊底（inset 2px 8px） |
| 菜单 hover | `rgba(240,67,110,0.05)` 轻染色 |

### 4.9 区块标题组

| 元素 | 规则 |
|---|---|
| 左标题 | 16~18px 700 `--text-primary`（如 Today's data / Operations Assistant） |
| 右 More 链接 | 13~14px 玫红，hover `#d9305c` + 下划线 |
| 间距 | 距下方内容 16px；相邻区块之间 24~32px |

### 4.10 数据统计卡（双变体）

| 变体 | 背景 | 结构 |
|---|---|---|
| 马卡龙带图标 | 四色浅底：粉 `#fce8ee` / 蓝 `#e7effc` / 紫 `#efeafc` / 绿 `#e5f6ec` | 左：标签 14px `--text-primary` → 数值 26~28px 700 → 注解 12px `--text-secondary`（Yesterday xxx）；右：48px 圆形图标（饱和底 + 白图标 20px）垂直居中 |
| 浅灰无图标 | `#f4f3f8` | 同上文字层级，无右侧图标 |

通用：`--radius-md`、padding 20px；数值 `font-variant-numeric: tabular-nums`；hover `translateY(-2px)` + `--shadow-md`；网格 `repeat(4,1fr)` gap 16px，行距 16px。

### 4.11 功能入口卡

| 元素 | 规则 |
|---|---|
| 容器 | 白底 + 1px `--card-border`，`--radius-md`、padding 16px |
| 图标块 | 40~44px 方块 `--radius-md`，马卡龙浅底 + 饱和图标 18~20px（粉/蓝/紫/绿/橙循环） |
| 标题 | 14~15px 600 `--text-primary` |
| 副标题 | 12px `--text-secondary`，距标题 2~4px |
| 布局 | 左图标右文案 gap 12px；网格 `repeat(4,1fr)` gap 16px |
| Hover | 边框 `#dcd8ea` + `--shadow-md` + `translateY(-2px)` |

## 5. 动效

| 场景 | 规则 |
|---|---|
| 通用过渡 | `transition: all 0.25~0.3s ease` |
| 悬浮微交互 | 卡片/按钮 `translateY(-2px)` + 阴影加深 |
| 入场 | `opacity 0→1` + `translateY(12px→0)`，0.5s `cubic-bezier(0.16,1,0.3,1)` |

**禁止**：深色背景、硬阴影、高饱和大面积色块、弹跳动画。

---

## 6. 布局

- **悬浮圆角容器**：body 12px padding + `#e9e7f0` 外底；`#app` 20px 圆角 + `--app-bg` 淡紫底 + 大柔和阴影（参考设计核心特征）
- 结构：白色 L 形框（顶栏横带 + 侧边栏 200px）+ 淡紫内容区卡片网格
- 内容区结构参考（自上而下）：引导横幅卡（4.8）→ 区块标题组（4.9）+ 数据统计卡两行（4.10）→ 区块标题组 + 功能入口卡网格（4.11）
- 数据卡/功能卡网格：`repeat(4, 1fr)`，gap 16px；响应式降为 2/1 列
